# DESIGN.md — визуальная система PrintForge

Дата: 2026-10-21 (M1). Источники и способ применения: [DESIGN_SOURCES.md](DESIGN_SOURCES.md). Продуктовый контекст: [PRODUCT.md](PRODUCT.md).

## Выбор направления

Рассмотрены три направления для рабочего редактора:

1. **«Цифровая мастерская» (выбрано).** Светлый рабочий стол, спокойные нейтральные поверхности, один медный акцент разметки; главное — деталь, её размеры и номер шага. Соответствует рабочей идее владельца и сцене использования (дневная работа в мастерской, длительные сессии).
2. Тёмная «контрольная панель» (по мотивам Taste `data-terminal`). Отклонено: тёмная тема по привычке категории, а не по сцене использования (craft-floor: «не выбирать light/dark по категории»); на длинных сессиях с чертежными сетками светлая сцена читается спокойнее.
3. `framed-sheet` (B2B-аналитика из Taste). Отклонено как «хорошо применённый набор, а не продукт с лицом»: не добавляет ничего предметного CAD-задаче.

База токенов — медианы исследования Taste app-screens (§9.5) с адаптациями ниже; режимы Impeccable: **Operate** для основного окна, **Read** для справочника.

## «Лицо» продукта (по Taste §2.3, выбрано до вёрстки)

- Акцент меди/керна: цвет разметки на металле — на выборе, фокусе и первичном действии.
- Размерные линии и контур печатного объёма как фирменные элементы сцены: размеры всегда с единицами, табулярными цифрами, на одной оси.
- Знак продукта: простая пластина с двумя отверстиями (силуэт из знака .app) в верхнем левом углу, рядом имя «PrintForge» и имя документа.

## Токены

```css
:root {
  --ground: #f7f6f4;   /* рабочий стол: тёплый нейтральный, не белый */
  --surface: #ffffff;  /* панели */
  --raised: #fbfaf9;
  --active: #efedea;   /* выбранный пункт списка/нав pill */
  --border: #e6e3df;   /* границы панелей, 1px */
  --rule:   #f0eeeb;   /* разделители строк */
  --control:#cfccc6;   /* границы полей ввода */
  --text:   #1b1a18;
  --muted:  #5d5a55;   /* 4.5:1 на ground/surface */
  --faint:  #6b6863;   /* placeholders, мета */
  --accent: #b45309;   /* медь: выбор, фокус, первичные метки */
  --accent-ink: #8a3f06;
  --primary: #211f1d;  /* первичная кнопка: почти чёрный, белый текст */
  --positive: #247b50; --negative: #c4242a;
  --pill-positive-bg: #dcfae5; --pill-positive-ink: #04250e;

  --scene-grid: #dcd9d4;
  --scene-grid-major: #c9c5bf;
  --sel-body: #b45309;   /* выбранное тело */
  --sel-face: #d97706;   /* выбранная грань */

```

- **Шрифт:** Onest (OFL, полноценная кириллица, табулярные цифры `font-variant-numeric: tabular-nums` для всех размеров и полей). Самохостинг woff2 в `app/ui/fonts/`. Один гарнитурный семейство; вторая гарнитура не нужна (Operate: «одной семьи часто достаточно»). Фиксированная шкала, не fluid; шаги 12/14/16/20.
- **Цифры:** размеры всегда с единицами («80 мм»), выравнивание вправо в повторяющихся полях; отображаемое округление не меняет значение в документе.
- **Иконки:** один набор, контурные, 16px, штрих ~1.5px (lucide-подобные, собственные SVG в одном стиле). Без цветных подложек; цвет — наследуемый muted/ink.

## Раскладка (UI-001)

Центр — сцена (наибольшая площадь). Слева колонка 240px: детали и история операций. Справа 300px: параметры выбранного/инструмента. Сверху 44px: основные действия + всегда видимая «?». Снизу 28px: единицы, габариты выделения, состояние вычисления. Один gutter 16px; единые левый/правый края колонок. Сворачивание: до 1100px левая колонка в раскрывашку, до 900px правая — в панель поверх, сцена не сжимается ниже 480px.

## Состояния выбора (сцена)

- Наведение: тонкий контур `--hover`, без заливки.
- Выбранное тело: заливка граней медью 35% + контур.
- Выбранная грань: `--sel-face`, плюс подпись площади.
- Выбранное ребро: `--sel-edge`, утолщённая линия 3px и маркеры концов — отличается формой, не только цветом.
- Пересчёт: последняя корректная модель остаётся, в строке состояния «Вычисление…» и индикатор занятости; никаких скелетонов вместо сцены.

## Параметры, ошибки, помощь

- Поле размера: метка сверху 12px muted, единицы в поле справа muted; выражение («длина / 2 - отступ») показывается как есть, вычисленное значение — подписью.
- Ошибка операции: в панели параметров, не модалка: красная метка + текст «что случилось и что сделать» + кнопка «Отменить изменение»; технический код — в раскрывашке.
- Подсказки (3 режима, HELP-002): «обучающий» — карточка с шагами и ссылкой на урок; «краткий» — одна строка; выключены — ничего всплывающего. Доступные имена (aria-label) сохраняются всегда.
- Справочник (Read): правая панель 380px, расширяемая до 560px; текст 16px, мера ~65ch; оглавление, поиск с подсветкой фрагмента, история переходов, «Показать в интерфейсе» (подсветка рамкой меди 2px на 1.2с, без выполнения команды).
- Уроки: нумерованные шаги — реальная последовательность действий, нумерация сохраняется (исключение из запрета индексных номеров). Панель урока снизу сцены: номер, текст, «Проверить», пропуск/пауза/выход.

## Движение

Только состояние: 150–250ms, opacity/transform; появление панелей, подсветка «Показать в интерфейсе», смена шага урока. `prefers-reduced-motion`: мгновенно. Никаких оркестрованных входов и декоративных анимаций.

## Адаптации источников (существенные разногласия)

- Сетка сцены, оси, размерные линии, границы полей — функциональные элементы CAD: запрет «thin rules / grid backgrounds» относится к декоративным поверхностям страниц, здесь не применяется (UI-011 прямо это разрешает).
- Нумерация шагов уроков сохраняется вопреки «no index numbering» (UI-011).
- Тёплый ground #f7f6f4 — не «cream with terracotta»: акцент-медь используется точечно на данных/выборе, палитра не ассистентская (нет жёлто-кремового фона с терракотовыми заливками).
- Панель справки поверх сцены — не модалка по рефлексу: чтение справки не должно терять состояние документа (HELP-001); модальных окон в M1 нет вовсе, ошибки — инлайн.
