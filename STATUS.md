## Что уже работает

**M0 (закрыт, проверено на macOS 27 arm64, MacBook Pro M3 8 ГБ):**
- Spike геометрии: пластина AC-01 (объём 18898.407105 мм³ точно), пересчёт 80→100 (23698.407105), выбор грани/ребра BRep + скругление, документ .printforge, STEP/STL/3MF.

**M1 (в работе):**
- Ядро Rust (`app/src-tauri/src/main.rs`): документ как authoritative-источник, история Undo/Redo, атомарное сохранение/открытие `.printforge` (zip), экспорт STL, слоты main/tutorial для уроков (HELP-009), восстановление worker после падения. `cargo check` чист.
- Dev-shim `scripts/dev_shim.py`: тот же IPC-контракт по HTTP (для проверок UI в браузере). Проверен сквозной AC-01: create → set length=100 (объём 23698.407105) → undo → 80.
- Справка: 15 статей в `docs/help/articles/` (все 10 команд реестра + первые шаги, устройство окна, горячие клавиши, словарь, недоступные команды, «в разработке» с явным статусом). Валидатор `scripts/check_help.py` — зелёный; индекс для приложения собирается `scripts/build_help_index.py`.
- Уроки 1–3 описаны в `app/shared/lessons.json` (проверка шагов по состоянию модели).
- Дизайн: PRODUCT.md, DESIGN.md (направление «Цифровая мастерская», токены, состояния), DESIGN_SOURCES.md (закреплённые commit, прочитанные файлы, способ применения). Шрифт Onest (кириллица, tabular-nums) самохостится.
