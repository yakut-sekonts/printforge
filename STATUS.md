# STATUS.md — статус PrintForge

Обновлено: 2026-10-21. Этап: M1 закрыт; следующий — M2.

## Что пользователь уже может сделать

Создать пластину с точными размерами и отверстиями, изменить размер с сохранением зависимых отступов, отменить/повторить (одно действие = одна транзакция), сохранить и заново открыть проект `.printforge`, экспортировать STL для слайсера. В любой момент: открыть справочник (⌘/), найти ответ по синонимам («дырка»), объяснить кнопку через «Что это?», пройти уроки на отдельной учебной модели, не трогая рабочий документ. Подсказки отключаются (3 режима, выбор сохраняется).

## Готовые части справки и обучения

15 статей (все 10 команд реестра + первые шаги, окно, клавиши, словарь, «почему кнопка серая», «в разработке» с явным статусом), валидатор целостности (зелёный), офлайн-поиск с фрагментами, «Показать в интерфейсе», уроки 1–3 (проверка шагов по состоянию модели; урок 2 пройден в браузере до «Урок завершён»).

## Как запустить

- Приложение: `cd app && cp ../backend/dist/printforge-geo src-tauri/binaries/printforge-geo-aarch64-apple-darwin && npm install && npx tauri build` → `app/src-tauri/target/release/bundle/macos/PrintForge.app` (128.5 МБ, sidecar внутри).
- Dev: `scripts/dev_shim.py` (порт 8787) + `cd app/ui && npx vite` → http://localhost:5173.
- Проверки: `backend/.venv/bin/python backend/spike_m0.py`; `... -m pytest backend/test_worker.py -q` (6/6); `scripts/check_help.py`; `scripts/build_help_index.py`.

## Ограничения / непроверенное

- Визуальные скриншоты UI — из браузерного прогона (vite+shim); внутри .app интерфейс не кликался (нет инструмента для WKWebView; screencapture без права «Запись экрана»). UI идентичен собранному dist, бэкенд-контракт проверен на обеих сторонах.
- Слайсер не установлен — часть AC-05/IO «открыть в слайсере» не проверена.
- Ошибка операции в UI не воспроизводилась end-to-end (в M1 нет надёжно падающей операции; путь ошибок реализован и будет проверен в M2 на скруглении).
- Нет подписи/notarization; ручной ввод путей вместо системных диалогов (M2); меш передаётся JSON (M2 — бинарный канал); автосохранение и восстановление после аварии — M2.
- Taste WARN по em-dash оставлен осознанно: русская типографская норма (тире в тексте справки), не английская привычка.
