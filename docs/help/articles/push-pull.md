# Push/Pull грани

## Назначение

Push/Pull меняет размер параметрической детали непосредственно на 3D-модели: выберите внешнюю плоскую грань и потяните оранжевый манипулятор по нормали. Точный итоговый размер можно ввести в правой панели.

## Пошагово

1. Создайте одну деталь из шаблона.
2. Щёлкните по внешней плоской грани.
3. Потяните оранжевый манипулятор. Во время движения показывается предварительный размер, документ ещё не изменяется.
4. Отпустите манипулятор либо введите точный размер и нажмите Enter.
5. Изменение записывается в историю одной операцией; одно нажатие ⌘Z возвращает прежний размер.

## Как меняется размер

- Верхняя грань пластины и шайбы меняет высоту.
- Боковые грани пластины меняют длину или ширину симметрично относительно центра.
- Поддерживаемые внешние грани L-кронштейна и корпуса изменяют соответствующий параметр шаблона.
- Значение округляется до 0,1 мм при перетаскивании; точный размер можно ввести вручную.

## Ограничения текущей версии

- Поддерживается одно параметрическое тело из штатного шаблона.
- Не поддерживаются импортированные сетки, цилиндрические грани, отверстия и произвольные грани после операций, меняющих топологию.
- Push/Pull сейчас изменяет исходный параметр шаблона, а не создаёт свободную локальную деформацию.
- Скругления, изгибы и выпуклости через перетаскивание грани будут добавляться отдельными операциями.

Если выбранная грань не поддерживается, правая панель показывает причину вместо неработающего манипулятора.

## Связанное

- «Размеры, единицы и параметры» — точный ввод и выражения.
- «История и отмена» — одна операция Push/Pull равна одному шагу Undo.
