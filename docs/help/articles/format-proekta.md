# Сохранение и формат проекта

## Назначение

Проект сохраняется в один файл `.printforge` — это архив с описанием модели: параметры, выражения-зависимости, единицы и версии. Файл можно переносить между компьютерами.

## Где

Кнопки «Сохранить проект» (⌘S) и «Открыть проект» (⌘O) на верхней панели. Путь вводится в поле рядом с кнопкой (ввод пути вместо системного диалога — ограничение текущей версии).

## Пошагово

1. Нажмите ⌘S, проверьте путь (по умолчанию `~/plate.printforge`), подтвердите.
2. Закройте проект или измените модель.
3. Нажмите ⌘O, укажите тот же файл: параметры и зависимости восстановятся.

## Что внутри файла

- `manifest.json` — версия схемы, приложения и геометрического ядра, единицы (мм).
- `document.json` — параметры, выражения, операции построения.

В проекте нет исполняемого кода: открытие файла безопасно. Повреждённый файл даёт понятную ошибку и не меняет уже открытую модель.

## Частые ошибки

- «Это не файл проекта PrintForge» — выбран файл другого формата.
- «Не удалось создать файл» — нет прав на папку; выберите другой путь.

## Связанное

- «Экспорт STL» — передача модели в слайсер (это не то же, что сохранение проекта).
