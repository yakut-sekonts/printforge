# AI-помощник

## Назначение

Необязательный помощник: описывает деталь обычным языком и предлагает план моделирования. Приложение, геометрия, справочник и уроки полностью работают с выключенным AI.

## Как это работает (важно)

1. Вы пишете запрос, например: «Создай шайбу: наружный диаметр 20 мм, внутренний 6 мм, высота 4 мм».
2. AI возвращает **план** — список проверяемых операций, а не готовую модель и не программу.
3. Приложение проверяет план: разрешённые команды, размеры, ссылки на детали, актуальность документа.
4. Показывается предпросмотр с объёмом и допущениями. **Рабочая модель пока не изменена.**
5. Вы нажимаете «Применить» — план применяется одной транзакцией. Один ⌘Z отменяет всю AI-операцию.

AI никогда не выполняет код и не меняет модель без вашего подтверждения.

Пока провайдер формирует ответ, кнопка **«Отменить запрос»** прерывает native HTTP-задачу. Отменённый или опоздавший ответ не проходит валидацию, не создаёт preview и не может быть применён.

## Неоднозначные запросы

Запрос вида «сделай отверстие побольше» без размера даёт либо уточняющий вопрос, либо явно подписанное **предположение** (например, «+50%: 4 → 6 мм»), которое видно перед применением и не может быть применено скрыто.

## Провайдеры

- **Выключен** — по умолчанию; всё работает.
- **Ollama на этом компьютере** — локальный endpoint `http://127.0.0.1:11434/v1`; модель пользователь устанавливает в Ollama самостоятельно.
- **OpenAI-совместимый endpoint** — явно заданные адрес и Model ID, например локальный FreeLLMAPI или внешний API. Совместимость конкретного endpoint проверяется отдельно.
- **Детерминированный планировщик** — только режим разработки для проверки конвейера, не нейросеть.

Откройте «Настроить», выберите провайдер, укажите Model ID и нажмите «Сохранить и проверить». Проверка запрашивает только `/models` и не передаёт данные проекта.

## Какие данные отправляются

Для плана передаются ваш текст и компактное описание документа: идентификаторы деталей, шаблоны, размеры и релевантные операции. Сетка, файл проекта и вся история не отправляются. Для внешнего endpoint обработка данных определяется его владельцем.

API key хранится в системном хранилище секретов. Он не записывается в `.printforge`, `ai-settings.json`, Git или обычный лог и не возвращается из backend в UI. В browser dev-shim ключ хранится только в памяти до остановки процесса.

## Спросить о PrintForge

Переключитесь на вкладку **«Справка»** и задайте вопрос о возможностях или командах PrintForge. Этот режим:

- ищет ответ только в поставляемом вместе с приложением `help/index.json`;
- работает при выключенном AI-провайдере и не выполняет сетевой запрос;
- показывает точный фрагмент найденной статьи и ссылки на источники;
- перечисляет только команды, которые одновременно присутствуют в статье и зарегистрированы в command registry.

Если подтверждённого совпадения нет, помощник прямо сообщает об этом и не придумывает ответ или команду. Вкладка **«Модель»** остаётся отдельным режимом: она формирует проверяемый план и требует настроенного провайдера.

## Частые ошибки

- «Предложение устарело» — документ изменился, пока формировался план. Нажмите «Пересчитать».
- «Команда не разрешена для AI» — план отклонён проверкой, документ не изменён.

## Связанное

- «История и отмена» — одна транзакция на план.
- Урок «AI-помощник» — первый запрос с проверкой.
