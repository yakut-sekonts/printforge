# Измерения

## Назначение

Точные замеры по BRep-геометрии (не по экранной сетке): габариты, объём, число тел, диаметр цилиндрической грани, расстояние между точками.

## Где находится

Правая панель, раздел «Измерения». Каждый результат подписан источником: «точная геометрия (BRep)».

## Что доступно

- **Габарит** — размеры ограничивающего параллелепипеда по осям, мм.
- **Объём** — в мм³, и число твёрдых тел.
- **Диаметр грани** — выберите цилиндрическую грань (отверстие, вал) щелчком и нажмите «Диаметр грани».
- **Расстояние** — между двумя точками, заданными координатами.

## Частые ошибки

- «Выбранная грань не цилиндрическая» — диаметр определён только для круглых поверхностей.
- «Грань не найдена» — модель перестроилась; выберите грань заново.

## Связанное

- «Проверка перед печатью» — габарит против стола принтера.
