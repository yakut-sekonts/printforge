# Булевы операции

CAD-термины: union (объединение), subtract (вычитание), intersect (пересечение) точных BRep-тел.

## Назначение

Собрать деталь из нескольких фигур или вырезать одну фигуру из другой: основание с бобышкой, корпус с выборкой, отверстие сложной формы.

## Где находится команда

Действие «Объединить / вычесть» рядом с моделью. Оно доступно, когда в документе хотя бы две детали. Новую фигуру можно добавить кнопкой «+ Форма» над сценой.

## Что нужно выбрать

- **Изменяемое тело** — деталь, которую вы хотите изменить.
- **Тело-инструмент** — вторая деталь. При вычитании её материал удаляется из изменяемого тела.
- «Сохранить второе тело» — оставить тело-инструмент отдельной деталью после операции; по умолчанию оно поглощается.

## Пошагово

1. Создайте первую форму, затем добавьте вторую через «+ Форма». При необходимости переместите её до нужного пересечения.
2. Выберите изменяемое тело, затем Shift + клик добавьте второе в выбор. Повторный Shift + клик убирает тело из выбора.
3. Откройте «Объединить / вычесть». Проверьте поля «Изменяемое тело» и «Тело-инструмент»; их можно явно выбрать из списков независимо от порядка кликов.
4. Выберите действие: объединить, вычесть второе из изменяемого или оставить общее пересечение. Нажмите «Применить к двум телам». Операция — одна запись в истории.

## Результат

Одна или несколько твёрдых тел; число живых тел показано в списке деталей. Если вычитание разрезало тело на части, вы увидите их количество.

## Частые ошибки

- Кнопки неактивны — «Сначала добавьте вторую деталь».
- Результат пуст — тела не пересекаются: переместите инструмент (операция «Переместить»).

## Как отменить

⌘Z возвращает обе детали как были.

## Связанное

- «Переместить, массив, зеркало, разделение» — соседние операции.
