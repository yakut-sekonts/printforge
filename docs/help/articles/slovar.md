# Словарь терминов

- **Деталь** — законченный изделий в проекте (пластина, крышка). У детали есть имя и параметры.
- **Тело** — замкнутый твёрдый объём. Деталь обычно состоит из одного тела; после некоторых операций тел может стать несколько — приложение сообщит их число.
- **Грань** — одна поверхность тела (плоская или изогнутая). Выбирается щелчком.
- **Ребро** — линия, где встречаются две грани. Нужно для скруглений и фасок.
- **Эскиз (профиль)** — плоский контур, из которого получают объём выдавливанием.
- **Сетка** — треугольное приближение модели для экрана и STL. Точная форма хранится отдельно (BRep); сетка всегда можно перестроить точнее или грубже.
- **BRep** — точное граничное представление тела в геометрическом ядре. Размеры, объём и экспорт STEP считаются по нему.
- **Параметр** — именованный размер (длина, диаметр). Параметры могут зависеть друг от друга выражениями.
- **Зазор** — намеренный промежуток между сопрягаемыми деталями (например, 0,2 мм на сторону между крышкой и корпусом).
- **Толщина стенки** — расстояние между наружной и внутренней поверхностями полой детали.
- **Допуск** — допустимое отклонение размера; не путать с зазором и с точностью сетки.
- **Слайсер** — программа, превращающая STL/3MF в задание принтеру (PrusaSlicer, OrcaSlicer, Cura).
