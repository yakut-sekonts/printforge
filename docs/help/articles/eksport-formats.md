# Экспорт STL, STEP и 3MF

## Назначение и выбор формата

- **STL** — для слайсера: сетка в миллиметрах. Самый совместимый вариант для печати.
- **STEP** — точная геометрия для других CAD: размеры и отверстия сохраняются в пределах допуска, авторская история не переносится.
- **3MF** — современный формат обмена для печати: хранит единицы и несколько объектов (например, корпус и крышку раздельно).

## Где находится команда

Кнопки «Экспорт STL / STEP / 3MF» в правой панели, когда есть деталь.

## Пошагово

1. Выберите формат и проверьте путь.
2. Для STL задайте точность сетки (линейное отклонение, по умолчанию 0,02 мм — для FDM достаточно).
3. Нажмите кнопку экспорта. В статус-баре появятся путь, размер файла и объём.

## Особенности

- Несколько раздельных тел (корпус и крышка): в STL они записываются в один файл как две оболочки; в 3MF — как отдельные объекты. Слайсеры обычно умеют разделять их обратно.
- Экспорт всегда строится из текущей подтверждённой модели; если последний ввод дал ошибку, выгружается последняя корректная ревизия — об этом предупреждает красная метка.

## Частые ошибки

- «Нет модели для экспорта» — создайте деталь.
- В слайсере не тот масштаб — выберите миллиметры при импорте.

## Связанное

- «Проверка перед печатью» — перед экспортом.
