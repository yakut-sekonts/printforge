# Mesh-операции, ремонт и упрощение

## Отдельный mesh workflow

После preview STL выберите исходные единицы и примените файл как mesh-документ. Исходные bytes встраиваются в `.printforge`; исходный файл после сохранения больше не нужен. Mesh остаётся треугольной сеткой: PrintForge не создаёт фиктивную параметрическую BRep-историю и не разрешает STEP-экспорт такого документа.

## Трансформация

Перенос и масштаб записываются отдельной операцией. Undo возвращает предыдущую сетку, а сохранение/открытие повторяет операции от встроенного исходника.

## Закрытие отверстия

Команда закрывает конкретный поддерживаемый дефект — один треугольный или четырёхугольный граничный цикл. До и после операции сохраняется число boundary/non-manifold edges. Если подходящего отверстия нет, команда завершается `mesh_repair_no_change` без commit.

Команда не заявляет исправление самопересечений. Этот статус остаётся `unknown`, пока не подключён отдельный надёжный алгоритм диагностики.

## Decimation

Topology-checked vertex clustering уменьшает число треугольников до объявленного диапазона около target ratio. Результат принимается только при сохранении числа компонент, Euler number, замкнутости исходной замкнутой сетки и заданного допуска объёма. Поэтому сквозное отверстие тора не должно исчезнуть.

Shape error — выборочная двусторонняя оценка расстояния до ближайших вершин. Это явно не глобальная гарантия Hausdorff distance. Если алгоритм не может попасть в диапазон без изменения топологии, операция отклоняется без commit.
