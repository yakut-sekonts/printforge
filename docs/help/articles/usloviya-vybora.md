# Почему команда недоступна

## Назначение

Недоступная команда не просто серая: подсказка и эта статья объясняют, какое условие не выполнено.

## Типовые причины

- **«Сначала создайте или выберите деталь»** — команда работает с моделью, а проект пуст. Создайте пластину.
- **«Пока нечего отменять»** — история пуста: выполните любое изменение, и «Отменить» станет активной.
- **«Нет модели для экспорта»** — экспорт возможен только для построенной детали без ошибок.

## Как узнать причину

Наведите указатель на серую кнопку: подсказка (в режимах «Обучающий» и «Краткий») называет недостающее условие. Кнопка «Что это?» открывает эту статью для любой недоступной команды.
