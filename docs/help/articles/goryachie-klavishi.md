# Горячие клавиши

| Сочетание | Действие |
|---|---|
| ⌘Z | Отменить |
| ⇧⌘Z | Повторить |
| ⌘S | Сохранить проект |
| ⌘O | Открыть проект |
| ⌘/ | Открыть/закрыть справочник |
| Escape | Снять выбор; выйти из режима «Что это?»; закрыть панель |

Сочетания также показаны в кратких подсказках к кнопкам. Все действия доступны и без клавиатуры.
