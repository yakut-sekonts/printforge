# Справочник PrintForge — исходники

Статьи — Markdown с YAML-шапкой. Поля шапки:

- `help_id` — стабильный идентификатор, на него ссылается реестр команд `app/shared/commands.json`.
- `title` — название простым языком.
- `synonyms` — слова, по которым статью должны находить («дырка» → «отверстие»).
- `commands` — связанные command_id из реестра.
- `related` — help_id связанных статей и уроков.

Проверка целостности (запускать при изменениях и в сборке):

```bash
backend/.venv/bin/python scripts/check_help.py
```

Скрипт проверяет: у каждой команды реестра есть статья с её help_id; нет статей-дубликатов; ссылки `related` и `commands` существуют; нет TODO/Lorem.
