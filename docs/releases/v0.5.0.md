# PrintForge v0.5.0

Ручное проектирование мышью — все согласованные инструменты в одном desktop-релизе.

## Новое

- «Форма мышью»: угловые и осевые ручки выбранного тела, XYZ в миллиметрах, Shift 0,1 мм, numeric input во время жеста, Escape и один шаг Undo.
- Редактируемые габариты в сцене: двойной щелчок по размеру или «Размеры», точный Preview и явное применение.
- Два режима габаритов: сохранение поддерживаемых отверстий/радиусов с параметрическим перестроением или affine-масштабирование всего BRep, включая STEP.
- Скругление и фаска: ручка на выбранном ребре, числовой размер, точный отменяемый Preview и подтверждение. Контекстное меню по правой кнопке.
- Привязки к сетке, центрам и границам других тел; подсказка и направляющая. Точное положение, поворот вокруг центра и выравнивание по XYZ.
- Круг/прямоугольник мышью на внешней плоской грани, точные размеры и положение профиля, выдавливание, blind/through вырез, изменение глубины стрелкой нормали.
- Именованная история: выбор целевого тела, редактирование поддерживаемых параметров, выключение операции, атомарное перестроение последующих действий.
- «Мягкая форма» для mesh: явное BRep → плотный mesh, радиус кисти, плавная деформация мышью, проверяемый Preview, STL/3MF и Undo до точного BRep.
- Офлайн-справка: 37 статей, 69 зарегистрированных команд. Schema 6 для новых операций; старые проекты читаются.

## Ограничения

Сохранение элементов работает только для поддерживаемых примитивов и однозначной истории. После Boolean, массива, поворота, affine-растяжения и для произвольного STEP предлагается масштабирование, без скрытого fallback. Простой face Sketcher не заменяет произвольный constrained Sketcher. Мягкая mesh-деформация не является точным CAD, не экспортируется в STEP и не гарантирует отсутствие всех самопересечений. Проверка таких пересечений остаётся unknown.

Preview не изменяет документ, Undo/Redo и файл; устаревшие ответы отбрасываются. Распространение — GitHub Releases, Apache-2.0, без Apple notarization/Windows Authenticode. Updater-подписи и существующий ключ сохранены; обновление доступно через колокольчик после публикации всех платформ.

Проверено 511 уникальных automated-тестов и 10 packaged-sidecar gates; отдельно выполнены browser и macOS native smoke. Проверки и недоступные сценарии перечисляются в [QA-отчёте](https://github.com/yakut-sekonts/printforge/blob/v0.5.0/docs/testing/QA_0.5.0.md). Полный каталог 179 ручных сценариев не объявляется повторно пройденным.
