# PrintForge v0.3.0

Feature-релиз расширенного параметрического моделирования, mesh workflow и более надёжного desktop runtime.

## Главное

- Constraint solver для эскизов: `coincident`, `horizontal`, `vertical`, `parallel`, `perpendicular`, `tangent`, `equal`, размерные и фиксирующие ограничения, residual/rank/DOF и constrained drag.
- Операции `revolve`, `sweep`, `loft`, оболочка, уклон, рёбра, параметрические посадки, резьбовые пары, разделение деталей и калибровка зазоров.
- Безопасный SVG/DXF import, BRep-рельеф текста и встроенные исходники для переносимых `.printforge` проектов.
- Persistent mesh-only workflow для STL/OBJ/PLY: transform, диагностика, закрытие поддерживаемых отверстий и topology-aware decimation.
- Experimental image relief из PNG/JPEG/WebP с детерминированным seed, preview без мутации и hash-bound Apply.
- Восстановление geometry worker после зависания или падения, ограниченные очереди и binary mesh channel.
- Расширенная offline-справка: 34 статьи, 58 команд и 13 интерактивных уроков.

## Проверка

- CAD/document/worker gate: 139 Python tests.
- Rust desktop tests: 13.
- TypeScript contracts и production Vite build.
- Help integrity: 34 статьи и 58 команд.
- Traceability: 97 требований и 63 test ID.
- Production Apple Silicon sidecar прошёл solver, mesh repair/decimation и image-relief smoke.
- Windows installer после сборки проходит silent install, installed binary/sidecar smoke и native startup/FPS/RSS gate до публикации релиза.

## Обновление

Установленный PrintForge v0.2.0 получает v0.3.0 через колокольчик. Update artifacts подписываются тем же ключом Tauri Updater, публичный ключ которого встроен в приложение.

## Установщики

- macOS Apple Silicon: `PrintForge_0.3.0_aarch64.dmg`.
- macOS Intel: `PrintForge_0.3.0_x64.dmg`.
- Windows x64: `PrintForge_0.3.0_x64-setup.exe`.

Сборки распространяются без Apple notarization и Windows Authenticode, поэтому ОС может показать стандартное предупреждение для unsigned open-source приложений. Исходный код распространяется по Apache-2.0.

## Ограничения

- Direct canvas Sketcher и generic face tools ещё не покрывают произвольное ручное редактирование всех элементов.
- General self-intersection detection/repair и ручное vertex editing mesh остаются в разработке.
- Image relief является декоративным mesh workflow и не заявляет инженерную точность.
