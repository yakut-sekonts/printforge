# PrintForge v0.7.0

Улучшения интерактивного эскиза для ручного моделирования.

- Полая прямоугольная деталь: выберите открываемую плоскую грань и задайте толщину стенок и дна. Preview, история и Undo сохраняют исходную модель при ошибке.
- Радиус окружности меняется ручкой мыши с отображением миллиметров. Заданный размер обновляется вместе с ручкой; другие геометрические ограничения проверяются solver.
- Повторный ввод длины или радиуса изменяет существующее ограничение. Локальный Undo восстанавливает прежнее значение.
- Контур может сочетать линии и дуги; переключение инструментов сохраняет общую конечную точку.
- Незаконченный контур можно отменить без потери других контуров; замкнутая цепочка отменяется одним локальным действием.
- Незакреплённые линии эскиза видны в текущей теме; ограничения показываются с понятными названиями и размерами; для пары элементов доступны поддерживаемые solver действия.

Новая оболочка пока поддерживает только прямоугольное тело без отверстий, скруглений и наклона; такие проекты требуют schema 8 и PrintForge 0.7.0. Это не полный промышленный Sketcher; не все ограничения доступны для дуг, а форма изменяется только в пределах поддерживаемых BRep-операций.

Результаты и ограничения проверки см. в [QA v0.7.0](https://github.com/yakut-sekonts/printforge/blob/main/docs/testing/QA_0.7.0.md). Поставка: GitHub Releases, Apache-2.0; без Apple notarization и Windows Authenticode, с подписанными обновлениями Tauri.
