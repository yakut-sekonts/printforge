# PrintForge v0.2.0

Feature-релиз прямого моделирования и sheet-metal операций.

## Главное

- Локальные операции на выбранной плоской грани: бобышка, blind/through вырез, окружность, прямоугольник, паз и кольцо.
- Сферические выпуклости и вмятины с точными диаметром, высотой и смещением.
- Скругления и фаски прямым выбором рёбер в 3D-сцене.
- До четырёх последовательных параллельных изгибов пластины с независимыми углами, радиусами и направлениями.
- Перенос through-вырезов на согнутую геометрию: прямоугольник через две bend-зоны; круг, кольцо и паз через одну.
- Каждая операция создаёт отдельную document-транзакцию и отменяется одним Undo.
- Vite обновлён до ветки 8; npm release toolchain не содержит известных уязвимостей по `npm audit`.

## Проверка

- Полный deterministic gate: 99 Python tests и 3 Rust tests, TypeScript/Vite build, help integrity, traceability и release-version.
- Локальная Apple Silicon release-сборка прошла строгую проверку ad-hoc code signature.
- Production geometry sidecar из собранной `.app` прошёл JSON-protocol smoke с реальным Open CASCADE kernel.

## Обновление

Установленные PrintForge v0.1.0 и v0.1.1 увидят v0.2.0 через колокольчик. Update artifacts подписаны тем же ключом Tauri Updater, публичный ключ которого встроен в приложение.

## Установщики

- macOS Apple Silicon: `PrintForge_0.2.0_aarch64.dmg`.
- macOS Intel: `PrintForge_0.2.0_x64.dmg`.
- Windows x64: `PrintForge_0.2.0_x64-setup.exe`.

Сборки распространяются без Apple notarization и Windows Authenticode, поэтому ОС может показать стандартное предупреждение для unsigned open-source приложений. Исходный код — Apache-2.0.

## Ограничения

- Перпендикулярные изгибы уже согнутых фланцев пока не поддерживаются.
- Штатные круглые отверстия шаблона должны целиком лежать вне криволинейной bend-зоны.
