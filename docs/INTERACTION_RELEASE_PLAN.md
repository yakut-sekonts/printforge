# PrintForge 0.6.0 — предсказуемое ручное проектирование

Один выпуск для согласованного набора улучшений. Это план работ, не заявление о готовности.

## Состав

- Выбор: preselection с названием области, перебор перекрывающихся граней, временное скрытие тел и восстановление видимости.
- Локальные элементы: связь выбранной поверхности с операцией отверстия/скругления, редактирование её размеров без масштабирования тела, ручки в сцене.
- Сохраняемые размеры: отступы профиля от выбранного края и равенство диаметров с проверкой зависимостей при перестроении.
- Эскиз: линии, дуги, окружности, замкнутые контуры и отверстия; интерактивные точки, геометрические ограничения, solver Preview и диагностика конфликтов.
- Сборочные связи: совмещение плоских граней и цилиндрических осей, зазор; отдельные тела и пересчёт связи без boolean union.
- Ошибки: выбранная проблемная область, объяснение и отдельно проверяемый допустимый размер скругления/фаски; не обещать глобальный максимум.
- Надёжность и печать: атомарный recovery безымянного основного документа, предложение восстановления при запуске, размещение на столе, абсолютные границы и диагностическая оценка тонких стенок с явными границами метода.

## Правила выпуска

- Preview не меняет документ; Apply — одна транзакция и один Undo. Stale document/revision отклоняются.
- Новые операции и зависимости переживают save/open/Undo/Redo. Ошибки не обрезают Redo.
- Обратная совместимость чтения старых проектов; новые возможности получают явную версию формата.
- Проверки изменённых компонентов и их связующих, native smoke, актуальные справка/обучение и release notes.
- Выпуск на GitHub только после проверок. Недоступные проверки отмечаются BLOCKED с причиной.
