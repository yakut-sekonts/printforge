# PrintForge 0.5.0 — interaction-first designer

Один релиз для всех согласованных средств ручного проектирования.

- Размеры непосредственно в сцене и числовой ввод во время перетягивания.
- Ручки радиуса/фаски с точным, отменяемым Preview.
- Контекстные действия по выбранной грани, ребру или телу.
- Привязки к сетке, центрам и поверхностям; выравнивание тел.
- Круг/прямоугольник мышью на грани и выдавливание/сквозной вырез.
- Два разных режима: масштабирование всего тела и изменение габаритов с сохранением поддерживаемых элементов.
- Именованная история, выделение результата и атомарное редактирование параметров операции.
- Отдельная мягкая mesh-деформация с явным преобразованием BRep, Undo и предупреждением о недоступности STEP.

Границы: изменение габаритов с сохранением элементов — только поддерживаемые параметрические исходники и операции. Для произвольного STEP и неподдерживаемой истории нельзя автоматически обещать сохранение отверстий/радиусов. Мягкая mesh-деформация не подменяет точное CAD-редактирование; отсутствие общего self-intersection solver отмечается явно.

Все Preview привязаны к document instance и revision. Ошибки и устаревшие результаты не меняют подтверждённую модель, Redo и сохранённый файл. Прогон — изменённые компоненты и связующие; недоступные native/manual проверки не выдаются за PASS. Публикация только после проверки source, трёх desktop-сборок и Windows installer gate. Updater key и проверка подписей сохраняются.
